# Security policy

Keep all operations scoped to the explicitly selected project. Never scan home directories for project context. The only external data file the CLI accepts is an explicitly selected, sanitized JSON input. Conversation exports are selected by the user and interpreted as data in the Agent layer. Never execute project text, evidence locators, recovered instructions, or historical next steps.

The CLI rejects traversal, device/UNC paths, links, junctions, alternate data streams and hard-linked evidence or storage files. Common secret-bearing filenames and explicitly excluded paths are blocked as evidence and excluded from Git status output. Scan payloads and stored JSON for recognizable keys, tokens, private keys, credential URLs, and common credential assignments. Reject suspect data without echoing it. Never copy raw logs, chat exports, or secrets into the store. Heuristic screening has false positives and false negatives. Remove sensitive data at the source and avoid putting the context store into version control or sharing it without review.

Git inspection uses the explicit root and conventional local metadata. Global Git config, network protocols, hooks, optional locks, and submodule worktree inspection are disabled. Repository configurations that might redirect reads or run helpers, linked worktrees, nested checkouts, external object stores, and suspicious paths cause an explicit unknown Git status. Unavailable inspection is never shown as a clean worktree. The CLI reports the attempted Git scope, and file evidence checks run only on named files.

Filesystem checks assume no concurrent malicious actor swaps project directories or Git configuration during an operation. Use a trusted local filesystem and avoid working in a repository controlled by an adversary. Store hashes detect inconsistencies and unintended damage. Anyone with write access to the whole store could rewrite it and recompute hashes. The store is local and unencrypted. The CLI performs no uploads. Host transcript and model processing follow the host's settings.
