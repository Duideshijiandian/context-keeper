# Capture policy

1. Identify the explicitly authorized project root and inspect the current capture ID. If uninitialized, initialize only when within the user's request. Review the current handoff and records for stable IDs and open questions.
2. Use only visible turns, observed tools, approved project files, and any specifically provided export. For exports, extract a narrow relevant portion locally and document which portion you saw. Do not put raw transcripts or logs in the payload.
3. Separate newly observed facts, user-reported progress, unverified ideas, technical decisions, and open tasks. Use a `task` or `issue` with `task_status: DONE` for an explicitly completed work item, including a user-reported completion. Set its evidence status independently so the validator can flag missing test evidence. Reuse a stable ID only if it is the same record. Ask for clarification on ambiguous high-impact conflicts or leave the competing records visible.
4. For verified claims, inspect the actual evidence and use `fingerprint --project ROOT --path RELATIVE` to get the SHA-256. Verify that the evidence supports the particular claim. Record the observed check and whether it covered the claimed result. A Git diff shows change, and does not establish intent or correct behavior.
5. Pass the smallest delta and a handoff with explicit source limits, a short reported narrative, and proposed next actions. When the project holds more than one task, keep each task's own summary in its record `content` and its own next actions in that record's `next_steps`, and reserve the handoff for the project-level view: the single handoff is replaced on every capture and cannot hold several tasks. Keep the payload in a deliberately selected scratch file with only sanitized content. If the manifest or a record precondition fails, reread state and reconcile before retrying.
6. Report changes and warnings. Preserve previous decisions with a new ID and `supersedes` when appropriate. A command exit of 0 means the capture operation succeeded; the returned findings still matter.
